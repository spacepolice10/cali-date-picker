# Cali Calendar

A `<cali-calendar>` custom element. One month at a time. Attributes configure the grid; CSS parts style the rest.

[Demo](https://spacepolice10.github.io/cali-date-picker/)

## jsDelivr

```html
<script
  type="module"
  src="https://cdn.jsdelivr.net/gh/spacepolice10/cali-date-picker@main/calendar.min.js"
></script>
<cali-calendar></cali-calendar>
```

Pin a tag instead of `@main` when you want a fixed build.
