Cali Calendar

Simple drop-in replacement for the native date picker. You can render one or more months in shadow DOM, style it with CSS parts, submit value of it as a form field and use events to react on data changes

Quick start

<cali-calendar> is a custom element with no dependencies. Load the module, then put the tag in the page.

Code

<script
  type="module"
  src="https://cdn.jsdelivr.net/gh/spacepolice10/cali-date-picker@main/calendar.min.js"
></script>
<cali-calendar></cali-calendar>

jsDelivr serves calendar.min.js from GitHub. Pin a tag instead of @main when you want a fixed build. There's no package manager support. Cali is just under 10kb minified and under 4kb gzipped & browsers easily handle up to 40 script modules in the page.

Style hooks

Host state:

  • [data-view="days"]
  • [data-view="months"]
  • [data-view="year"]

Elements and states:

  • ::part(switcher)
  • ::part(prev) / ::part(next)
  • ::part(months) / ::part(years)
  • ::part(calendar)
  • ::part(pane) / ::part(caption)
  • ::part(weekday)
  • ::part(offset)
  • ::part(date) / ::part(current) / ::part(selected) / ::part(disabled) / ::part(in-ranges) / ::part(preselected)
  • ::part(mn-butn) + ::part(m1)–::part(m12)
  • ::part(yr-butn)

Code

cali-calendar[with-switcher]::part(calendar) {
  min-height: 16em;
  align-content: start;
}

cali-calendar::part(pane) {
  display: grid;
  width: 100%;
  grid-template-columns: repeat(7, minmax(0, 1fr));
}

cali-calendar::part(in-ranges) {
  background: color-mix(in srgb, var(--accent-color) 22%, transparent);
}

cali-calendar::part(selected) {
  background: var(--accent-color);
  color: var(--secondary-color);
}

Attributes

Boolean attributes are on / off by presence. Values are strings.

Attribute What it does
value="YYYY-MM-DD" Selected date YYYY-MM-DD, or YYYY-MM-DD/YYYY-MM-DD with with-ranger. Paints selected, sets the form value, opens on the start month. Empty clears the selection.
minval="YYYY-MM-DD" Earliest selectable date. Earlier day buttons render disabled and ignore clicks. Views stay navigable. Set once; not observed.
maxval="YYYY-MM-DD" Latest selectable date. Later day buttons render disabled and ignore clicks. Views stay navigable. Set once; not observed.
with-weekdays Shows weekday labels (Su–Sa) in the first row.
with-offset Adds empty leading cells so the 1st lines up with its weekday. Needs with-weekdays to make sense.
week-starts-on="mo" First day: su / mo / tu / we / th / fr / sa (or 0–6). Wins over locale; default is Sunday (or the locale default when set).
locale="de-DE" BCP 47 tag: month + weekday names and default week start. Explicit week-starts-on wins.
with-switcher Shows prev / next plus month and year buttons to switch data-view between days, months, and year panels.
prev-text="Back" Previous-period button label. Default Prev; empty hides the text for icon-only buttons.
next-text="Fwd" Next-period button label. Default Next; empty hides the text for icon-only buttons.
months="3" How many month panes to show (1–12). Default 1. Distinct from months-view.
with-ranger Pick two dates. First click is starts; hover paints in-ranges; second click saves starts/ends. The next click starts over. change detail includes date, starts, and ends.
year-view="2025" Initial visible year when there is no value. After connect, drive with .yearView.
months-view="12" Initial visible month (1–12) when there is no value. After connect, drive with .monthsView.
name="booking" Form-associated. Submits the ISO date; form reset clears value.

Bare month

No attributes. Current month, day buttons only.

Weekdays

Labels in the first row. Without offset, the 1st still starts in column one. locale localizes the labels (and month names) and picks the locale's default week start.

Offset cells

Empty leading cells so the 1st lines up with its weekday.

Monday first

Week starts on Monday. Default is Sunday.

Period switcher

Prev / next move the period. Month and year buttons toggle data-view and pick up selected while that panel is open. A fixed calendar height keeps the page from jumping between views. locale="ru-RU" localizes month + weekday names (and the switcher labels) and picks Monday as the default week start.

Selected vs today

value paints selected. Today keeps current even when it is not selected.

Limits

minval and maxval disable day buttons outside the limits. Only the buttons are gated — months, year, and prev / next stay navigable.

Months

months paints that many sibling panes. Host CSS lays them out in a horizontal scroll strip.

Open on a month

year-view and months-view set the initial view when there is no value.

Ranger

with-ranger picks two dates. Hover (or focus) the second date to preview in-ranges. The saved value is YYYY-MM-DD/YYYY-MM-DD. Clicking again starts a new range.

Form value

Form-associated: name submits ISO YYYY-MM-DD. Reset clears value.

change / beforechange

change reports the date. beforechange is cancelable — this one rejects Sundays.

Bind an input

Keep parsing in a native input; the calendar stays strict ISO YYYY-MM-DD. Sync both ways with change. Clearing the input clears the calendar.

yearView / monthsView from JS

After connect, drive the visible period with .yearView and .monthsView.

React

Load React from a CDN. <cali-calendar> is a custom element, so keep value in React state and listen for change on a ref — React does not wire custom events to onChange.

Popover

Native popover. change writes the date on the trigger and closes the popover.

Dialog

Native dialog. Pick a date — change writes the date and closes the dialog.

Week numbers (recipe)

Core does not ship week numbers. Decorate the open shadow DOM: one ISO-8601 number per 7-cell row, plus an 8th grid column. Pair with Monday start, weekdays, and offset so rows line up. The switcher works as usual — the observer repaints the numbers after every navigation.

Styling

A playful copy-paste theme, scoped by host id (#theme-play) so it never leaks into other calendars. Date, month-grid, and year-grid buttons share one chunky look with hover lift and a pop on selected. Click the month button in the switcher to see the months panel: each month also carries m1–m12 next to mn-butn, with a Tabler-icon SVG-mask ::after badge (needs a modern browser for ::part()::after). Prev / next go icon-only the same way: empty prev-text / next-text with Tabler chevron masks.
