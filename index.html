Cali Calendar

One month at a time. Attributes configure the grid; CSS parts and data-view style the rest.

Style hooks

Host state:

  • [data-view="days"]
  • [data-view="months"]
  • [data-view="year"]

Elements and states:

  • ::part(period-switcher)
  • ::part(previous) / ::part(next)
  • ::part(view-months) / ::part(view-year) / ::part(selected-view)
  • ::part(calendar)
  • ::part(weekday)
  • ::part(offset)
  • ::part(date-button) / ::part(current-date-button) / ::part(selected-date-button) / ::part(disabled-date-button)
  • ::part(months-button) / ::part(selected-months-button)
  • ::part(year-button) / ::part(selected-year-button)

Code

cali-calendar[with-switcher]::part(calendar) {
  height: 16em;
  align-content: start;
}

cali-calendar[data-view="months"]::part(calendar) {
  grid-template-columns: repeat(3, minmax(0, 1fr));
}

cali-calendar::part(current-date-button) {
  border-color: var(--accent-color);
}

cali-calendar::part(selected-view),
cali-calendar::part(selected-date-button),
cali-calendar::part(selected-months-button),
cali-calendar::part(selected-year-button) {
  background: var(--accent-color);
  color: var(--secondary-color);
}

Attributes

Boolean attributes are on / off by presence. Values are strings.

Attribute What it does
value="YYYY-MM-DD" Selected date. Paints selected-date-button, sets the form value, opens the calendar on that month. Empty clears the selection.
minval="YYYY-MM-DD" Earliest selectable date. Earlier day buttons render disabled with disabled-date-button and ignore clicks. Views stay navigable. Set once; not observed.
maxval="YYYY-MM-DD" Latest selectable date. Later day buttons render disabled with disabled-date-button and ignore clicks. Views stay navigable. Set once; not observed.
with-weekdays Shows weekday labels (Sun–Sat) in the first row.
with-offset Adds empty leading cells so the 1st lines up with its weekday. Needs with-weekdays to make sense.
week-starts-on="mo" Starts the week on Monday. Default is Sunday; any value other than mo is Sunday.
with-switcher Shows prev / next plus month and year buttons to switch data-view between days, months, and year panels.
year-view="2025" Initial visible year when there is no value. After connect, drive with .yearView.
months-view="12" Initial visible month (1–12) when there is no value. After connect, drive with .monthsView.
name="booking" Form-associated. Submits the ISO date; form reset clears value.

Bare month

No attributes. Current month, day buttons only.

Code

<cali-calendar></cali-calendar>

Period switcher

Prev / next move the period. Month and year buttons toggle data-view and pick up selected-view while that panel is open. A fixed calendar height keeps the page from jumping between views.

Code

<cali-calendar
  with-weekdays
  with-offset
  with-switcher
></cali-calendar>

Code

Range

minval and maxval disable day buttons outside the range. Only the buttons are gated — months, year, and prev / next stay navigable.

Code

<cali-calendar
  value="2026-09-13"
  minval="2026-09-10"
  maxval="2026-09-20"
  with-weekdays
  with-offset
  with-switcher
></cali-calendar>

change / beforechange

change reports the date. beforechange is cancelable — this one rejects Sundays.

Code

calendar.addEventListener("beforechange", (event) => {
  const date = new Date(`${event.detail.date}T00:00`);
  if (date.getDay() === 0) event.preventDefault();
});

Bind an input

Keep parsing in a native input; the calendar stays strict ISO YYYY-MM-DD. Sync both ways with change. Clearing the input clears the calendar.

Code — HTML

<input
  id="bound-input"
  type="date"
  min="2026-09-10"
  max="2026-09-20"
  value="2026-09-13"
>
<cali-calendar
  id="bound"
  value="2026-09-13"
  minval="2026-09-10"
  maxval="2026-09-20"
  with-weekdays
  with-offset
></cali-calendar>

Code — JavaScript

calendar.addEventListener("change", (event) => {
  input.value = event.detail.date;
});

input.addEventListener("change", () => {
  calendar.value = input.value;
});

Popover

Native popover. change writes the date on the trigger and closes the popover.

Example

Code — HTML

<button type="button" popovertarget="date-popover" id="date-trigger">
  Pick a date
</button>
<div id="date-popover" popover>
  <cali-calendar with-weekdays with-offset with-switcher></cali-calendar>
</div>

Code — JavaScript

calendar.addEventListener("change", (event) => {
  trigger.textContent = event.detail.date;
  popover.hidePopover();
});

popover.addEventListener("toggle", (event) => {
  if (event.newState !== "open") return;
  const rect = trigger.getBoundingClientRect();
  const gap = 5;
  const top =
    rect.bottom + gap + popover.offsetHeight > window.innerHeight
      ? rect.top - gap - popover.offsetHeight
      : rect.bottom + gap;
  popover.style.top = `${Math.max(0, top)}px`;
  popover.style.left = `${rect.left}px`;
});

  dialog.showModal();
});

calendar.addEventListener("change", (event) => {
  trigger.textContent = event.detail.date;
  output.textContent = event.detail.date;
  dialog.close();
});

></script>
