Bare month

No attributes. Current month, day buttons only.

<cali-calendar></cali-calendar>

Weekdays

Labels in the first row. Without offset, the 1st still starts in column one. 

<cali-calendar with-weekdays></cali-calendar>

Offset cells

Empty leading cells so the 1st lines up with its weekday.

<cali-calendar with-weekdays with-offset></cali-calendar>

Monday first

Week starts on Monday. Default is Sunday.

<cali-calendar
  week-starts-on="mo"
  with-weekdays
  with-offset
></cali-calendar>

Period switcher

Prev / next move the period. Month and year buttons toggle data-view and pick up selected-view while that panel is open. A fixed calendar height keeps the page from jumping between views. 

<cali-calendar
  with-weekdays
  with-offset
  with-switcher
></cali-calendar>

Selected vs today

value paints selected-date-button. Today keeps current-date-button even when it is not selected. 

<cali-calendar
  value="2026-09-13"
  week-starts-on="mo"
  with-weekdays
  with-offset
  with-switcher
></cali-calendar>

Open on a month

year and month set the initial view when there is no value. 

<cali-calendar
  year="2025"
  month="12"
  with-weekdays
  with-offset
  with-switcher
></cali-calendar>

Form value

Form-associated: name submits ISO YYYY-MM-DD. Reset clears value. 

<form>
  <cali-calendar name="booking" with-weekdays with-offset></cali-calendar>
  <button>Submit</button>
  <button type="reset">Reset</button>
</form>

change / beforechange

change reports the date. beforechange is cancelable — this one rejects Sundays. 

calendar.addEventListener("beforechange", (event) => {
  const date = new Date(`${event.detail.date}T00:00`);
  if (date.getDay() === 0) event.preventDefault();
});
Pick a date. Sundays stay unselected.

year / month from JS

After connect, drive the visible period with .year and .month. 

calendar.year = 2025;
calendar.month = 12;

Popover

Native popover. change writes the date on the trigger and closes the popover. 

<button type="button" popovertarget="date-popover" id="date-trigger">
  Pick a date
</button>
<div id="date-popover" popover>
  <cali-calendar with-weekdays with-offset with-switcher></cali-calendar>
</div>
calendar.addEventListener("change", (event) => {
  trigger.textContent = event.detail.date;
  popover.hidePopover();
});

popover.addEventListener("toggle", (event) => {
  if (event.newState !== "open") return;
  const rect = trigger.getBoundingClientRect();
  const gap = 5;
  const top =
    rect.bottom + gap + popover.offsetHeight > window.innerHeight
      ? rect.top - gap - popover.offsetHeight
      : rect.bottom + gap;
  popover.style.top = `${Math.max(0, top)}px`;
  popover.style.left = `${rect.left}px`;
});
